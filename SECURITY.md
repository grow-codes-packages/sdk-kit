# Security policy

Please report security problems **privately** by email to
[opensource@grow.codes](mailto:opensource@grow.codes). Do not open a public issue for a suspected
vulnerability.

Include the affected version or commit, a description, steps to reproduce and the impact. Never send
real credentials. We acknowledge reports within 3 working days and give a first assessment within 10
working days.

In scope: the generator (`sdk_kit/`), the template (`template/`) — which reaches every generated
repository — the conformance suite and the reusable workflows. A problem in the template is fixed
here and rolled out to all service repositories with `sdk-kit sync`.

Only the latest release of sdk-kit receives fixes.
