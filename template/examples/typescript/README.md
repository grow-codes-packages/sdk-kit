# TypeScript example

```sh
(cd ../../typescript && npm install && npm run build)
npm install
GROW___KEY_UPPER___URL=http://127.0.0.1:<port> GROW___KEY_UPPER___TOKEN=... npm start
```

Replace the `file:` dependency in `package.json` with a version (`npm install @grow-codes/__KEY__`)
to run it against the published package.
