# sdk-kit

**sdk-kit** builds and maintains the Grow Codes open-source SDKs: 17 service repositories in
[`grow-codes-packages`](https://github.com/grow-codes-packages), each shipping the **same API in
TypeScript, Rust, Go, Python and Java**.

| Part | Where | What |
| - | - | - |
| Specification | [`spec/SPEC.md`](spec.md) | names, defaults, error codes, environment rules, category interfaces, Docker contract |
| Service catalog | `spec/services.json` | the 17 services and their template token values |
| Conformance suite | `conformance/` | language-neutral scenarios run by every package against the real service |
| Template | `template/` | repository files, five language packages, Dockerfiles, examples, docs, workflows |
| Generator | `sdk_kit/`, `bin/sdk-kit` | `sdk-kit new / sync / list / check` ([guide](generate.md)) |
| Reusable workflows | `.github/workflows/` | CI, Docker integration, docs and release pipelines the generated repos call ([reference](workflows.md)) |
| Docs theme | `theme/` | Grow Codes branding for MkDocs Material ([details](theme.md)) |

## Principles

- **One contract.** The spec decides; no language drifts. A public API change lands in all five
  languages in one pull request.
- **Generated core, owned service code.** Shared code (core, secrets, logging, tracing, testing,
  workflows, Docker harness, shared docs) carries a `Generated by sdk-kit` header and is refreshed
  with `sdk-kit sync`. Client, config and service modules belong to the service repository.
- **Tested like users use it.** Unit tests with ≥ 90 % coverage gates, plus integration tests that
  pack each package, install it into a consumer project and run it against the real service in
  Docker.
- **Small, permissive dependencies.** Runtime licences from a fixed allowlist, checked in CI.
